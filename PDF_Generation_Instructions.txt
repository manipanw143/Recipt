
# 📄 PDF Generation Instructions - OPTIMIZED FOR LARGE FILES

## 🚨 IMPORTANT: For 800+ receipts, DON'T use single file method!

## Method 1: BATCH PROCESSING (RECOMMENDED for 500+ receipts)
The script creates smaller batch files automatically:
- receipts_batch_01_(1-100).html
- receipts_batch_02_(101-200).html
- etc.

Steps:
1. Open each batch file in Chrome/Edge
2. Print to PDF (Ctrl+P → Save as PDF)
3. Use the merge_pdfs.py script to combine all PDFs
4. Or use online PDF merger tools

## Method 2: WeasyPrint (BEST for large files)
Direct Python PDF generation:
```bash
pip install weasyprint
```
Then run the script - it will generate PDF directly without browser.

## Method 3: Browser Print (ONLY for small batches < 200 receipts)
1. Open the main HTML file
2. Press Ctrl+P (Windows/Linux) or Cmd+P (Mac)
3. Select "Save as PDF"
4. Settings:
   - Paper: A4
   - Margins: Default
   - Scale: 100%
   - Background graphics: ON
   - Headers/footers: OFF

## Method 4: Command Line (If wkhtmltopdf installed)
```bash
# For batch files
wkhtmltopdf --page-size A4 --margin-top 0.5in receipts_batch_01.html batch_01.pdf
wkhtmltopdf --page-size A4 --margin-top 0.5in receipts_batch_02.html batch_02.pdf
# ... repeat for all batches

# Merge PDFs
pdftk batch_*.pdf cat output all_receipts_final.pdf
```

## Method 5: Online Tools
1. Convert each batch HTML to PDF using online converters
2. Use online PDF merger tools to combine

## 🔧 Troubleshooting Large Files:
- Browser crashes: Use batch files instead
- Memory errors: Reduce batch size to 50 receipts
- Slow performance: Close other browser tabs
- PDF too large: Split into multiple final PDFs

## 📊 Performance Guide:
- 1-100 receipts: Single file OK
- 101-500 receipts: Use batch processing
- 500+ receipts: Use WeasyPrint or command line
- 1000+ receipts: Split into multiple sessions
